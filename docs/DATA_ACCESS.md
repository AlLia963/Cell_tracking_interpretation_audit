# Data and input access

The executable constructed examples require no study data. The public repository
contains analysis source, exact input formats, commands and compact validation
receipts. It contains no competition images, coordinates, model weights, private
notebooks, reviewer reports or manuscript files. The development catalog includes
source identities and score/run records.

## Public upstream resources

- Bacterial images and reference lineages: [Cell Tracking Dataset](https://doi.org/10.5281/zenodo.11237127).
- Released Cell-TRACTR weights: [checkpoint record](https://doi.org/10.5281/zenodo.14509424).
- Epithelial images and curated labels: [EpiCure dataset](https://doi.org/10.5281/zenodo.20607705).
- Competition inputs: the [official competition](https://www.kaggle.com/competitions/biohub-cell-tracking-during-development).

Use each resource under its own terms. These resources do not contain all the
generated predictions, stage captures or complete correspondence families used
in the paper. Downloading their public images is not a substitute for those inputs.

## Prepared study companions

| Companion | Contents | Used by |
|---|---|---|
| `controlled_companion_LOCAL_ONLY.zip` | Exact real worked-audit NPZs, original complete results, later costs and interfaces | Worked path audit and source tables 1–52 |
| `full_study_inputs_LOCAL_ONLY.zip` | Saved predictions and intermediate captures for the retained original analyses | The 30 analysis routes in `paper/run_suite.py` |
| `expanded_evidence_LOCAL_ONLY.zip` | Normalized saved graphs, references, frame families, reports and all comparison statuses | Expanded archive and 216 endpoint checks |
| `figure_inputs_LOCAL_ONLY` | Actual image crops, saved masks, provenance and plot inputs | Paper figure rendering |
| `case_reuse_LOCAL_ONLY` | Required actual inputs, relative configurations and replay records for 12 alternative cases and four original figure identities | Generic case extraction and relocation check |

These are author-held materials, not public downloads. For journal review, request
the named packages through the submission's confidential author/editor channel.
The submission owner must approve the transfer under the applicable input terms.
No reviewer account, transfer permission or public controlled-data URL is implied
by this repository. Until that arrangement is made, the unrestricted examples can
be run, but the complete controlled study cannot be reproduced from Git alone.

The source-duty producer is included under its verified Apache-2.0 upstream
license, with author instrumentation and executed-version identity recorded in
`paper/licenses/Harmonic-Fusion-NOTICE.md` and `paper/SOURCE_INDEX.json`.
No separate controlled-source package is needed for the current code.

## Submission owner action

Supply a permitted confidential delivery channel for the controlled companions
and confirm access for the reviewers before submission. This repository provides
the package inventory and executable unrestricted entry; it does not fabricate an
access authorization on behalf of the data owner.
