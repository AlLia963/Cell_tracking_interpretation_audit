Tables 48–52. Their original author-layout paths and source pins are unchanged.
They are historical records, not portable current entry points, and must not be
run with guessed path replacements. No old cohort or timing was rerun for this
mapping correction. Current portable checks use paper/review_smoke.py,
paper/review_d47.py, paper/verify_primitive_path.py and paper/probe_contracts.py.
Current resource entry points are paper/measure_d47_resources.py and
paper/measure_coupled_resources.py; original cost records retain their original
source versions and measurement scopes.
